# OpenCode native-origin wire codec

NPR-01 and NPR-02 implement the v1 canonical wire format for the separately installed `2.0.26-libra-native.1` producer. This codec is preparatory infrastructure; the installed official OpenCode remains independent. A decoded receipt is untrusted data and does not prove native origin. Source A requires the later approved-build, transport, issuer, signature, coordinates and original-field checks before any opaque archive admission.

`observed_agents::native_origin::codec` exposes `decode_receipt`, `decode_endpoint` and `decode_policy` for original JSON bytes, followed by `signing_bytes`, `endpoint_bytes` and `policy_bytes`. Raw readers reject duplicate keys (including escaped equivalent names), unknown members, invalid JSON and invalid Unicode. Read the original raw proof, rather than a `serde_json::Value` that has already discarded duplicates. Serde's public wire structs are convenient data containers; Serde decoding alone does not enforce the complete grammar. Canonical functions always revalidate public fields after mutation. No function signs, verifies, loads an issuer, performs I/O or constructs `NativeProven`/`OpaqueEncryptedBytes`.

Receipt input is at most 8192 bytes, including original whitespace. Endpoint/policy JSON and their canonical outputs are bounded to 65536 bytes. The grammar accepts v1, the current producer literal, four fixed protocols, lowercase digest/nonce hex, nonzero u32 key generation and field lengths, ordered distinct fields and a canonical padded base64 64-byte signature. Declared field lengths do not authorize allocations or expand existing artifact limits. Signature syntax is checked, while cryptographic validity is reserved for NPR-11.

Canonical preimages use the domain plus NUL, version once, big-endian u32 values, raw digest bytes and byte-length-prefixed original UTF-8. Strings reject C0/C1 controls and keep combining characters and percent spelling unchanged. Receipt route is bounded to 256 bytes; session, message and fragment to 1024. Endpoint URLs must already have the exact ASCII HTTPS serialization, without userinfo, query or fragment; normalization, explicit default ports and empty query/fragment delimiters are rejected. Policy lists are sorted and distinct, and the macOS absolute Libra command path is preserved byte for byte. Installation paths may differ and therefore produce different policy digests. No endpoint or path is approved just because it appears in a descriptor.

The frozen fixture `tests/fixtures/agent_transcripts/native_origin_receipt_v1.json` is copied byte for byte from the reviewed NPR-01 fixture. Three receipt, two installation policy and two endpoint vectors were prepared independently in Python, checked in TypeScript, and compared with Rust's bytes and SHA256. All receipt signatures are deliberately invalid all-zero synthetic values. These tests prove wire parity, not a successful native model session. Receipt domains and all v1 fields remain unchanged from R11; only the current producer version literal follows the audited 2.0.26 source.

Run the six `npr_02_*` library tests under `internal::ai::observed_agents::native_origin::codec::tests`. They cover parity, closed grammar, original duplicate members, UTF-8 preservation, raw caps, error diagnostics and the absence of authority. No runtime registration, migration or public CLI changes occur in this card. Existing receipt-less sessions continue to require partial handling. The later family release owns final full-suite and real-source acceptance.
