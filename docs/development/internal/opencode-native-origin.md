# OpenCode native-origin wire codec

NPR-01 and NPR-02 implement the v1 canonical wire format for the separately installed `2.0.26-libra-native.1` producer. This codec is preparatory infrastructure; the installed official OpenCode remains independent. A decoded receipt is untrusted data and does not prove native origin. Source A requires the later approved-build, transport, issuer, signature, coordinates and original-field checks before any opaque archive admission.

`observed_agents::native_origin::codec` exposes `decode_receipt`, `decode_endpoint` and `decode_policy` for original JSON bytes, followed by `signing_bytes`, `endpoint_bytes` and `policy_bytes`. Raw readers reject duplicate keys (including escaped equivalent names), unknown members, invalid JSON and invalid Unicode. Read the original raw proof, rather than a `serde_json::Value` that has already discarded duplicates. Serde's public wire structs are convenient data containers; Serde decoding alone does not enforce the complete grammar. Canonical functions always revalidate public fields after mutation. No function signs, verifies, loads an issuer, performs I/O or constructs `NativeProven`/`OpaqueEncryptedBytes`.

Receipt input is at most 8192 bytes, including original whitespace. Endpoint/policy JSON and their canonical outputs are bounded to 65536 bytes. The receipt grammar accepts v1, the explicit `.1` and `.2` producer literals, four fixed protocols, lowercase digest/nonce hex, nonzero u32 key generation and field lengths, ordered distinct fields and a canonical padded base64 64-byte signature. Declared field lengths do not authorize allocations or expand existing artifact limits. Signature syntax is checked, while cryptographic validity is reserved for NPR-11.

Canonical preimages use the domain plus NUL, version once, big-endian u32 values, raw digest bytes and byte-length-prefixed original UTF-8. Strings reject C0/C1 controls and keep combining characters and percent spelling unchanged. Receipt route is bounded to 256 bytes; session, message and fragment to 1024. Endpoint v1 still requires exact ASCII HTTPS serialization without userinfo, query or fragment. Endpoint v2 has one narrow exception: `anthropic-messages` at exactly `https://api.anthropic.com/v1/messages?beta=true`, encoded under the v2 endpoint domain. Alternate query spelling, normalization, explicit default ports, proxies and empty query/fragment delimiters are rejected. Policy lists are sorted and distinct, and the macOS absolute Libra command path is preserved byte for byte. Installation paths may differ and therefore produce different policy digests. No endpoint or path is approved just because it appears in a descriptor.

The frozen fixture `tests/fixtures/agent_transcripts/native_origin_receipt_v1.json` is copied byte for byte from the reviewed NPR-01 fixture. Three receipt, two installation policy and two v1 endpoint vectors were prepared independently in Python, checked in TypeScript, and compared with Rust's bytes and SHA256. The separate Anthropic v2 endpoint vector uses independent Python encoding and the exact reviewed producer fixture. All receipt signatures are deliberately invalid all-zero synthetic values. These tests prove wire parity, not a successful native model session. Receipt domains and all v1 fields remain unchanged from R11; the only accepted producer literals are the reviewed `.1` and the separate `.2` candidate.

Run the six `npr_02_*` library tests under `internal::ai::observed_agents::native_origin::codec::tests`. They cover parity, closed grammar, original duplicate members, UTF-8 preservation, raw caps, error diagnostics and the absence of authority. No runtime registration, migration or public CLI changes occur in this card. Existing receipt-less sessions continue to require partial handling. The later family release owns final full-suite and real-source acceptance.

NPR-11 prepares the crate-private `verify_with_conn` authenticator for the later single reasoning factory. Its sealed `VerifiedProducerReceipt` has private fields and a read-only wire accessor, with no Serde/default/conversion constructor. This card does not enable native capture or create opaque artifacts. Consumers supply the original raw receipt, actual session/message/part coordinates and original decoded UTF-8 string fields. They must independently establish authorized source association; copying receipt coordinates into the expected input cannot establish that association.

Verification uses real ring Ed25519 over the unchanged canonical preimage and only the current active registered key/generation. It checks the original field names/order/byte lengths/SHA256 and source coordinates, then the independently measured current producer and exact approved stable policy. Unknown builds, malformed/absent/verify-only/revoked registry, missing/drifted trust, removed trusted directories, changed observer path/template or differing loaded plugin bytes refuse admission and keep capture partial. The verifier requires the signed protocol and endpoint digest as a pair in the selected build: `.1` permits only its two OpenAI Responses endpoints; `.2` additionally permits the exact Anthropic Messages endpoint v2. Separate protocol and digest set membership is insufficient.

All registry, exporter trust and trusted-directory reads use the caller's single transaction. A consumer that persists data must obtain the existing writer-lock-first transaction before its first read, retain that snapshot for admission, and own commit/rollback. The verifier itself performs no writes or nested pool acquisition and never assumes automatic trust removal succeeded. Pending/import must recheck current permission. Runtime measurement hashes the current producer off Tokio, validates executable/parent posture and reads the bounded regular observer file without following its final symlink. This retains the reviewed best-effort filesystem boundary, including the same-UID limitation; it does not add race-free execution guarantees.

The observer command is the actual canonical current Libra executable. Its transient binary SHA is deliberately absent from signed stable policy, so an update at that same approved path keeps the path/template/rendered bytes/event map/deadline binding. Moving the executable or changing the plugin requires a newly prepared and explicitly registered installation. The seven `npr_11_*` unit tests include immutable NPR03 vector verification, independently re-signed synthetic negative cases and current-transaction rejection. The optional controlled local authority case measures the actual approved private binary when `LIBRA_NATIVE_TEST_PRODUCER` is supplied; its public deterministic key and receipts are explicitly synthetic. Neither these cases nor the immutable vector's unapproved synthetic build nonce prove a real provider field or archive GO.

## Native attestation launch isolation (FIX-OG-NATIVE-LAUNCH-01)

The installation challenge runs with fresh, owner-only home, configuration, data, cache, state and temporary directories inside the owned private installation. Its initial environment is constructed explicitly; caller `TMPDIR`, runtime-loading overrides and host HOME/XDG settings are not inherited. The temporary directory must be canonical, owned by the current user, mode 0700 and empty before the producer starts. A failed precondition or cleanup refuses registration with the existing fixed challenge error.

Scratch is retained for the child lifetime and cleaned after normal exit, failure or timeout; cancellation cleanup is best effort. Inherited process-group descendants are terminated while the leader PID is still reserved. A parent crash or SIGKILL can leave an owner-only scratch directory, which later challenges never reuse. This isolation applies to the Libra-launched installation challenge. Separately launched OpenCode sessions retain their own runtime requirements, and the current `.3` SOURCE/Source A and real-field archive gates remain unproven.

The 15 initial keys are PATH, HOME, TMPDIR, XDG_CONFIG_HOME, XDG_DATA_HOME, XDG_CACHE_HOME, XDG_STATE_HOME, LANG, LC_ALL, TERM, NO_COLOR, DO_NOT_TRACK, OPENCODE_LIBRA_NATIVE_ORIGIN, OPENCODE_LIBRA_NATIVE_KEY_DIR and OPENCODE_LIBRA_COMMAND. PATH is `/usr/bin:/bin:/usr/sbin:/sbin`; LANG/LC_ALL are the fixed `C.UTF-8` label, TERM is `dumb`, NO_COLOR/DO_NOT_TRACK/ORIGIN are `1`. Challenge output uses canonical ASCII independently of installed locale data. The six directory values belong to this invocation; key-directory and command values keep the existing measured binding. The real worktree remains the working directory.

Private directories are validated before spawn. Scope stays at the existing best-effort local-user tier: current-user ownership and 0700 prevent other users from planting reusable Bun libraries; this adds no fd-exec or same-user malware guarantee. The leader is observed with nonblocking WNOWAIT before group termination and direct-child reap. Explicit recursive removal runs off the async thread, and cleanup failure takes precedence over success bytes or an earlier child error. Drop cleanup is best effort; orphan directories after parent death are never reused. Synthetic helpers verify process mechanics only. Selected real Bun consumption and every-launch requirements of the registered producer lane remain separate blocking SRC029/OG-24.3 checks.
