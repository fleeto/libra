# Issue #664：修复 compat_index_flag_preservation 守卫截断源码问题（2026-10-31）

> 模板版本：v2.15。来源：[libra-tools/libra#664](https://github.com/libra-tools/libra/issues/664)。状态：计划已建立；IFP-01 为 `pending`，本地已完成验证方案，待实施代码合入。

## 文档职责

本文规划并记录修复 Issue #664 报告的 `tests/compat/compat_index_flag_preservation.rs` 兼容守卫在遇到内联 `#[cfg(test)]` 项时提前截断源码导致生产 helper 计数漏算和后续生产代码跳过检查的问题。

### 适用范围

- 重构 `tests/compat/compat_index_flag_preservation.rs` 中的生产代码提取逻辑，使用 AST 解析安全剔除 `#[cfg(test)]` 项与语句，同时完整保留后续生产代码及精确行号映射。
- 补充内联 `#[cfg(test)]` 项位于生产 helper 调用与未分类直接替换之前的回归测试用例。
- 保持既有的最低 helper 覆盖阈值（`>= 5`）与直接替换白名单机制。

### 非目标

- 不放宽或降低暂存命令对 `update_preserving_flags` 的最低调用阈值（保持 `>= 5`）。
- 不改动任何生产命令、公开接口、CLI 参数、配置或用户文档。
- 不引入外部未注册的新依赖。

### 成功定义

- `compat_index_flag_preservation` 在源码包含内联 `#[cfg(test)]` 时能够正确扫描后续全部生产代码，准确统计 helper 使用并在出现未分类直接调用时准确定位行号。
- 补充的回归用例通过，既有的全量暂存命令守卫通过。
- `cargo +nightly fmt --all --check`、`cargo clippy --test compat_index_flag_preservation -- -D warnings` 通过。
