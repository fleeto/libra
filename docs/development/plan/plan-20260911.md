## 已决议设计决策与数据库合同

- ADR-PI-01：以D1现有CHECK的原七值为唯一白名单SSOT，d1_client.rs仅抽取集合供DDL和preflight共同消费，不改变任何D1 schema允许集合。Pi/Hermes/未来未知tag全部拒绝。网络前以同一个短事务分页读取object身份、refs、metadata、capture catalog/generation，经现有云投影脱敏后写0700目录/0600私有spool（生命周期由PI-09唯一实现，残留永不复用）。事务不做object解码、不跨网络持锁；内存按页受限，spool随现有catalog量线性增长，不新增会拒绝no-Pi合法大仓的整集合内存cap。后续只消费冻结spool，synced只更新其身份；当前权限/tombstone/generation/撤权fence仍复验，漂移拒绝发布，不能复活erase。磁盘不足在remote前失败并清理，不报告备份成功。
- ADR-PI-WRITE：任何local-only writer必须先持久提交agent_session identity/现有capture intent，再写trace对象、object_index或refs；不允许对象已发布而kind行未提交。crash可以留空session，但不能留下围栏不可见的本地only trace。PI-05用隔离的未来兼容catalog fixture（仅测试DDL允许额外tag，不关闭生产CHECK）验证拒绝；PI-01真实迁移后用实际Repository schema重跑围栏门。
- ADR-PI-RECOVERY：一旦存在local-only capture，本计划内同仓整仓`libra cloud sync`持续拒绝。force、disable hooks、只删session行均不能恢复；本计划没有可承诺的无损恢复命令。需要同仓云备份者须等待独立DEFER-PI-08完整graph兼容/迁移验收，期间采用用户选定的外部完整仓库备份。错误与指南明确此范围，不指导清空DB/删trace绕过。

- ADR-PI-02：v3 disk leaf只按固定source的恢复算法；live按实际getLeafId。branch/compaction/metadata entry不是独立用户turn；不把树叶变化当prompt。v3内system message、usage、context_edit与compaction.systemMessage按PI-00冻结的entry type白名单处理：system role与usage不开用户turn；context_edit只作非turn元数据，不改写已采集target原文（与Pi raw history语义一致）；未知type记partial。
- ADR-PI-03：project-local `.pi/extensions/libra-hooks.ts`仅在受信project加载；运行前再检查ctx.isProjectTrusted，不写trust state（含`~/.pi/agent/trust.json`），不注册`project_trust` handler，也不替用户加`--approve`。marker+内容摘要核ownership，用户同名文件零覆盖；fixed absolute executable、fixed argv、stdin allowlist JSON，不使用shell。
- ADR-PI-04：callback返回undefined，不改message/tool/context；session_start的resume/reload不能被固定session-start键永久去重或错建新session。turn/checkpoint终态以`agent_settled`为准，`agent_end`不是终态；`before_agent_start`只有`messageType === "user"`对应用户prompt。稳定事件/entry/phase与turn对应由PI-00表证明，缺ID只partial。turnIndex不是跨进程主键。
- ADR-PI-05：thinking 文本及 thoughtSignature/encrypted/关联 unknown 块普通保留，缺 native 来源记 Unproven/Partial；不新增 Pi opaque capability。artifact 认证另行规划，不阻塞数据保存。
- Repository CHECK仅走ADR-CAP-CHECK/PI-07专用连接路径，preserve已有行/FK/index/trigger/receipt；Global/System/Derived零写，ID大于当前tip；已有Pi数据禁止down/drop回滚。发布后前滚。旧reader oracle与未知kind负向测试先行。
- extension 的普通观察 projection 与 DATA-CAP-20261019 授权 thinking carrier 进入现有 pending；tool乱序state最多64项/1MiB/300秒惰性过期，超限记录partial/retryable诊断；child总deadline2秒/最多8并发/最多3尝试共享deadline，不能阻塞provider循环或存raw outbox。
