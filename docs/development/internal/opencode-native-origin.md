# OpenCode native-origin wire codec

NPR-01 and NPR-02 implement the v1 canonical wire format for the separately installed `2.0.26-libra-native.1` producer. This codec is preparatory infrastructure; the installed official OpenCode remains independent. A decoded receipt is untrusted data and does not prove native origin. Source A requires the later approved-build, transport, issuer, signature, coordinates and original-field checks before any opaque archive admission.

`observed_agents::native_origin::codec` exposes `decode_receipt`, `decode_endpoint` and `decode_policy` for original JSON bytes, followed by `signing_bytes`, `endpoint_bytes` and `policy_bytes`. Raw readers reject duplicate keys (including escaped equivalent names), unknown members, invalid JSON and invalid Unicode. Read the original raw proof, rather than a `serde_json::Value` that has already discarded duplicates. Serde's public wire structs are convenient data containers; Serde decoding alone does not enforce the complete grammar. Canonical functions always revalidate public fields after mutation. No function signs, verifies, loads an issuer, performs I/O or constructs `NativeProven`/`OpaqueEncryptedBytes`.

Receipt input is at most 8192 bytes, including original whitespace. Endpoint/policy JSON and their canonical outputs are bounded to 65536 bytes. The grammar accepts v1, the current producer literal, four fixed protocols, lowercase digest/nonce hex, nonzero u32 key generation and field lengths, ordered distinct fields and a canonical padded base64 64-byte signature. Declared field lengths do not authorize allocations or expand existing artifact limits. Signature syntax is checked, while cryptographic validity is reserved for NPR-11.

Canonical preimages use the domain plus NUL, version once, big-endian u32 values, raw digest bytes and byte-length-prefixed original UTF-8. Strings reject C0/C1 controls and keep combining characters and percent spelling unchanged. Receipt route is bounded to 256 bytes; session, message and fragment to 1024. Endpoint URLs must already have the exact ASCII HTTPS serialization, without userinfo, query or fragment; normalization, explicit default ports and empty query/fragment delimiters are rejected. Policy lists are sorted and distinct, and the macOS absolute Libra command path is preserved byte for byte. Installation paths may differ and therefore produce different policy digests. No endpoint or path is approved just because it appears in a descriptor.

The frozen fixture `tests/fixtures/agent_transcripts/native_origin_receipt_v1.json` is copied byte for byte from the reviewed NPR-01 fixture. Three receipt, two installation policy and two endpoint vectors were prepared independently in Python, checked in TypeScript, and compared with Rust's bytes and SHA256. All receipt signatures are deliberately invalid all-zero synthetic values. These tests prove wire parity, not a successful native model session. Receipt domains and all v1 fields remain unchanged from R11; only the current producer version literal follows the audited 2.0.26 source.

Run the six `npr_02_*` library tests under `internal::ai::observed_agents::native_origin::codec::tests`. They cover parity, closed grammar, original duplicate members, UTF-8 preservation, raw caps, error diagnostics and the absence of authority. No runtime registration, migration or public CLI changes occur in this card. Existing receipt-less sessions continue to require partial handling. The later family release owns final full-suite and real-source acceptance.


NPR-15 adds an immutable public catalog for the macOS arm64 `2.0.26-libra-native.1` artifact accepted by NPR-08. Lookup requires the exact version, build nonce and independently measured producer binary SHA256. Official OpenCode, a future private version, an unknown nonce or changed binary is rejected. The catalog binds the reviewed source archive/manifest, complete patch/manifest, frozen lock, measured build inputs, Bun runtime and actual Claude review. A catalog match is not native origin, issuer registration or artifact admission.

Only public policy constants are compiled: the two exact source-derived OpenAI Responses endpoints, their canonical digests, reviewed builtin set, frozen observe-only template, event map, 30000 ms deadline and transport policy. No issuer key, installation command path or rendered plugin digest is in the catalog. The public endpoint constants are not evidence of a successful live model response; NPR-08's free and authorized paid observations all failed and remain partial.

`render_observer` and `installation_policy` are pure helpers for later NPR-09 controlled registration. The caller must establish the actual canonical executable path and loaded observer bytes independently; an export or installation descriptor cannot authorize its own path. Rendering uses the exact reviewed template and three ordered, closed substitutions. An invalid path, residual template slot, oversized or differing observer is refused. The returned `codec::Policy` is untrusted wire data. It contains the private per-install path/digest only at runtime, never as a compiled catalog constant. It is hashed with the unchanged codec preimage. Two independently prepared Python vectors, checked against the producer TypeScript codec, pin distinct installation paths and policy digests.

The six `npr_15_*` library tests cover exact identity, actual binary/source/runtime evidence, rejection, a closed public catalog without installation secrets, and the canonical policy/endpoint/template bindings. NPR-11 prepares the crate-private `verify_with_conn` authenticator for the later single reasoning factory. Its sealed `VerifiedProducerReceipt` has private fields and a read-only wire accessor, with no Serde/default/conversion constructor. This card does not enable native capture or create opaque artifacts. Consumers supply the original raw receipt, actual session/message/part coordinates and original decoded UTF-8 string fields. They must independently establish authorized source association; copying receipt coordinates into the expected input cannot establish that association.

Verification uses real ring Ed25519 over the unchanged canonical preimage and only the current active registered key/generation. It checks the original field names/order/byte lengths/SHA256 and source coordinates, then the independently measured current producer and exact approved stable policy, protocol and endpoint digest. Unknown builds, malformed/absent/verify-only/revoked registry, missing/drifted trust, removed trusted directories, changed observer path/template or differing loaded plugin bytes refuse admission and keep capture partial. The current approved catalog contains only OpenAI Responses endpoints; any future additional protocol needs its own endpoint binding.

All registry, exporter trust and trusted-directory reads use the caller's single transaction. A consumer that persists data must obtain the existing writer-lock-first transaction before its first read, retain that snapshot for admission, and own commit/rollback. The verifier itself performs no writes or nested pool acquisition and never assumes automatic trust removal succeeded. Pending/import must recheck current permission. Runtime measurement hashes the current producer off Tokio, validates executable/parent posture and reads the bounded regular observer file without following its final symlink. This retains the reviewed best-effort filesystem boundary, including the same-UID limitation; it does not add race-free execution guarantees.

The observer command is the actual canonical current Libra executable. Its transient binary SHA is deliberately absent from signed stable policy, so an update at that same approved path keeps the path/template/rendered bytes/event map/deadline binding. Moving the executable or changing the plugin requires a newly prepared and explicitly registered installation. The seven `npr_11_*` unit tests include immutable NPR03 vector verification, independently re-signed synthetic negative cases and current-transaction rejection. The optional controlled local authority case measures the actual approved private binary when `LIBRA_NATIVE_TEST_PRODUCER` is supplied; its public deterministic key and receipts are explicitly synthetic. Neither these cases nor the immutable vector's unapproved synthetic build nonce prove a real provider field or archive GO.
